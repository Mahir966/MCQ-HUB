Installation Guide

Step-by-Step Android Installation

Installing an APK on Android is straightforward. Follow these verified steps to download, verify, authorize, and run MCQ HUB safely on your smartphone.

1

Download the MCQ HUB APK

Tap the Download APK button. Your web browser (Chrome, Firefox, Samsung Internet, etc.) will initiate the direct HTTPS download. When finished, find the file in your browser's download manager or your device's Downloads folder.

Target file: MCQHub-v11.apk (~43.05 MB). Ensure the full file finishes downloading.
2

Verify Download Authenticity

Always download the APK exclusively from this official project website or official GitHub release assets. Do not download modified APKs from untrusted third-party forums or file-hosting mirrors.

Check the exact size (~45,144,258 bytes). An incomplete download will trigger a "Problem parsing package" error.
3

Allow "Install Unknown Apps" Permission

Modern Android (Android 9.0+) requires permission per-app before installing an APK. When you open the file, Android will prompt you. If prompted, navigate to your device settings:

Settings → Apps → Special app access → Install unknown apps → [Your Browser/Files app] → Toggle "Allow from this source"
4

Handle Google Play Protect Responsibly

Keep Google Play Protect turned ON. Play Protect scans apps for security. Because MCQ HUB is distributed directly as an APK and not hosted on the Play Console, Play Protect may prompt: "Unrecognized app".

Tap "More details" and select "Install anyway". Never disable Play Protect globally.
5

Complete the Package Installation

After granting installation permission, Android's system package installer will display: "Do you want to install this application?" Tap Install. The installation typically completes in 5 to 10 seconds.

The APK is signed with APK Signature Scheme v2 for tamper-proof binary integrity.
6

Launch & Configure Your Profile

Tap Open or launch MCQ HUB from your app drawer. On first startup, the 4-step Onboarding wizard allows you to pick your Version (Bangla / English), enter your student nickname, and choose your favorite theme.

No email, mobile number, or password required. Start practicing immediately!

Google Play Protect & Sideloading Safety

Google Play Protect is an essential security layer on Android. When installing apps manually outside the Google Play Store, Android marks them as coming from an "Unknown Source." This warning is normal for open, independently built educational APKs. We strictly advise users NOT to disable Play Protect. You can safely proceed by verifying that you downloaded the APK from this official repository, inspecting the file checksum, and tapping "Install anyway".

Installation Troubleshooting

  • This error occurs either when the download was interrupted before finishing, or if your device is running an unsupported Android version. MCQ HUB requires Android 9.0 (Pie, API 28) or higher. Check your downloaded file size against the verified size (~43.05 MB / 45,144,258 bytes). If smaller, delete the file and download it again.

  • If you previously installed an older development or test version of MCQ HUB with a different keystore signature, Android will block the update to protect application data. Uninstall the previous test version from your phone, restart your device, and install Version 11.

  • Web browsers like Google Chrome display a generic warning whenever downloading any executable file (.apk, .exe, .dmg). Tap "Download anyway". If the download does not start, long-press the Download APK button and select "Download link".

  • Open your phone's built-in Files or File Manager app (e.g. Google Files, Samsung My Files). Go to the Downloads or Installation Files (APK) category. Tap MCQHub-v11.apk to begin installation.

  • The APK file is ~45 MB and requires approximately ~55 MB of internal storage space once installed. Ensure your smartphone has at least 150 MB of free internal storage space before initiating installation.

  • Advanced users can verify binary integrity using PowerShell: Get-FileHash MCQHub-v11.apk -Algorithm SHA256 or Linux/macOS: sha256sum MCQHub-v11.apk. The official SHA-256 hash for Version 11 is: 2774CF9BDE6E68D7DEF012B21424181644370D957078AA7B50F6EA5AA015C994.
